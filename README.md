# Фикс The Jackbox Party Pack для РФ
Скрипт автоматически заменяет сервер игры на резервный, который (возможно) работает в РФ.
<br>  
![img](preview.png)

## Использование скрипта
- Скачайте и запустите [билд](https://github.com/klovik/jackbox-ru-fixer/releases/download/1.4/jackbox-ru-fixer-1.4.exe)
- Укажите путь до папки с игрой
- Выберите номер одного из резервных серверов (на конце **НЕ** jackboxgames.com), или выберите `Ручной ввод`, чтобы самостоятельно указать сервер
- Готово, запускайте игру как обычно

## Способ с помощью VPN
- Если вы до этого пользовались моим скриптом, то с его же помощью смените сервер игры на стандартный (blobcast.jackboxgames.com)
- Подключитесь к прокси/vpn серверу и создайте комнату как обычно
- Игроки должны присоединяться через любой из альтернативных сайтов из списка ниже

## Альтернативные сайты для игры
- https://jackbox.su
- https://jackbox.ru
- https://jack.trgu.ru
